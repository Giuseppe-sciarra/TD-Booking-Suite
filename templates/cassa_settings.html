Ponte cassa

Un piccolo programma su un computer del negozio, nella stessa rete della cassa o con la cassa attaccata via USB: prende gli scontrini da stampare e li passa alla cassa. 1. Installa Python 3 da python.org (spunta Add python.exe to PATH); per l'USB anche pip install pyserial. 2. Crea il codice qui sotto e copialo. 3. Scarica ponte_cassa.py. 4. Nella cartella del file apri il Prompt dei comandi e incolla questa riga, con il tuo codice. Lascia la finestra aperta: se è chiusa, gli scontrini restano in coda.

python ponte_cassa.py {{ bridge_url }} IL-CODICE
