Google Calendar degli operatori

{% if google %}Attivo{% else %}Spento{% endif %}

Con un client OAuth di Google Cloud, nella scheda di ogni operatore compare Collega Google Calendar: i suoi impegni su Google diventano orari occupati e le sue prenotazioni vanno nel suo calendario. In Google Cloud: attiva la Google Calendar API, nella schermata di consenso scegli Esterno e pubblica l'app «In produzione» (in prova il collegamento scade dopo 7 giorni), poi crea un ID client di tipo Applicazione web con questo URI di reindirizzamento: {{ google_uri }}. Sul PC Windows senza indirizzo pubblico usa un client di tipo App desktop e collega aprendo il programma da questo PC, all'indirizzo 127.0.0.1

Outlook e Microsoft 365 degli operatori

{% if microsoft %}Attivo{% else %}Spento{% endif %}

Con un'app registrata in Microsoft Entra, nella scheda di ogni operatore compare Collega Outlook, per gli account Outlook.com e Microsoft 365: i suoi impegni diventano orari occupati e le sue prenotazioni vanno nel suo calendario.

  1. Su entra.microsoft.com: Registrazioni app › Nuova registrazione. Tipi di account: account in qualsiasi directory organizzativa e account Microsoft personali. URI di reindirizzamento: piattaforma Web, {{ microsoft_uri }}
  2. Certificati e segreti › Nuovo segreto client: copia subito la colonna Valore, non l'ID. Segna la scadenza: quando scade, metti qui un segreto nuovo
  3. Autorizzazioni API › Microsoft Graph › Autorizzazioni delegate: Calendars.ReadWrite, User.Read, offline_access
  4. Qui sotto incolla l'ID applicazione (client), dalla Panoramica dell'app, e il valore del segreto, poi Salva
